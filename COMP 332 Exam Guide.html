    The whole course in 60 seconds

    كل المادة في دقيقة

    A computer takes input, processes it using a program, and gives output. The program and data both sit in memory. The CPU repeats one loop forever: fetch an instruction from memory, then execute it. Parts talk to each other over a bus. Memory comes in layers: tiny and fast near the CPU, big and slow far away. A small fast cache sits between the CPU and main memory to keep copies of what you use most.

    الحاسوب يأخذ مدخلات (input) ويعالجها (process) حسب برنامج (program) ويعطي مخرجات (output). البرنامج والبيانات كلاهما في الذاكرة (memory). المعالج CPU يكرر حلقة واحدة دائمًا: يجلب تعليمة من الذاكرة (fetch) ثم ينفّذها (execute). الأجزاء تتواصل عبر الناقل (bus). الذاكرة طبقات: صغيرة وسريعة قرب المعالج، وكبيرة وبطيئة بعيدًا عنه. والـ cache ذاكرة صغيرة سريعة بين المعالج والذاكرة الرئيسية تحتفظ بنسخ من الأشياء الأكثر استخدامًا.

    Core, Processor, CPU · الفرق بينها
    Exam definition · Core
    Core = an individual processing unit on a processor chip (it has a control unit, ALU, registers and maybe cache). A core can be equal in function to a CPU in a single-CPU system.
    النواة (Core) = وحدة معالجة مستقلة على شريحة المعالج (فيها وحدة تحكم وALU ومسجّلات وربما cache). النواة قد تعادل في وظيفتها معالجًا (CPU) في نظام بمعالج واحد.
    • CPU: the part that fetches and executes instructions (ALU + control unit + registers).
    • Processor: a physical piece of silicon with one or more cores. With many cores it is a multicore processor.
    • Core parts: instruction logic (fetch and decode), ALU, load/store logic (moves data to and from main memory via cache).
    • CPU: الجزء الذي يجلب التعليمات وينفذها (ALU + وحدة تحكم + مسجّلات).
    • المعالج (Processor): قطعة سيليكون فيزيائية فيها نواة أو أكثر. إذا فيه عدة أنوية فهو معالج متعدد الأنوية (multicore).
    • أجزاء النواة: منطق التعليمات (الجلب والفك)، ALU، منطق التحميل/التخزين (ينقل البيانات من وإلى الذاكرة عبر الكاش).

    5. Von Neumann Machine (IAS)

    آلة فون نيومان
    LONG QUESTIONSlides 35–41 · "very important"

    Almost every modern computer has this same structure, so they are called von Neumann machines. Designed by mathematician John von Neumann (1946, completed 1952) at the Princeton Institute for Advanced Studies = IAS computer. Its main idea is the stored program: data and program live in the same memory, so the machine can change its own program or data.

    تقريبًا كل الحواسيب الحديثة لها نفس البنية، لذلك تُسمى آلات فون نيومان. صممها عالم الرياضيات جون فون نيومان (١٩٤٦، اكتملت ١٩٥٢) في معهد برينستون للدراسات المتقدمة = حاسوب IAS. فكرتها الأساسية البرنامج المخزّن (stored program): البيانات والبرنامج في نفس الذاكرة، فيستطيع الجهاز تعديل برنامجه أو بياناته بنفسه.

    Exam answer · Three key concepts (Slide 36)
    1. Data and instructions are stored in a single read-write memory.
    2. The contents of memory are addressable by location, regardless of the type of data in it.
    3. Execution occurs sequentially (one instruction after another) unless explicitly changed.
    1. البيانات والتعليمات تُخزَّن في ذاكرة واحدة للقراءة والكتابة.
    2. محتويات الذاكرة يمكن الوصول إليها بالعنوان (addressable by location) بغض النظر عن نوع البيانات.
    3. التنفيذ يحدث بالتسلسل (تعليمة بعد أخرى) إلا إذا تغيّر ذلك صراحةً.
    Trick: S-A-S = Stored, Addressable, Sequential.
    Exam answer · What a von Neumann machine has (Slide 37)
    • A main memory storing both data and instructions.
    • An ALU that operates on binary data.
    • A control unit that interprets instructions in memory and makes them execute.
    • Input/Output (I/O) equipment operated by the control unit.
    • ذاكرة رئيسية تخزن البيانات والتعليمات.
    • وحدة ALU تعمل على البيانات الثنائية.
    • وحدة تحكم تفسّر التعليمات الموجودة في الذاكرة وتجعلها تُنفَّذ.
    • معدّات إدخال/إخراج (I/O) تُشغّلها وحدة التحكم.
    IAS memory & registers · ذاكرة IAS والمسجّلات

    IAS memory: 1,000 locations called words, each 40 bits. A word can hold data, or two 20-bit instructions, each with an 8-bit opcode and a 12-bit address.

    ذاكرة IAS: ١٠٠٠ موقع تسمى كلمات (words)، كل واحدة ٤٠ بت. الكلمة تحمل بيانات أو تعليمتين كل واحدة ٢٠ بت، وكل تعليمة فيها opcode من ٨ بت وعنوان من ١٢ بت.

    RegisterMeaning · المعنى
    MBRMemory Buffer Register: holds a word to be stored in memory or sent to I/O (or just read).
    يحمل الكلمة المراد تخزينها في الذاكرة أو إرسالها لـ I/O (أو المقروءة للتو).
    MARMemory Address Register: the address in memory of the word to be written from or read into MBR.
    يحدد عنوان الكلمة في الذاكرة المراد قراءتها أو الكتابة منها.

    يحمل opcode (٨ بت) للتعليمة الجاري تنفيذها.
    IBRInstruction Buffer Register: temporarily holds the right-hand instruction of a word.
    يحتفظ مؤقتًا بالتعليمة اليمنى من الكلمة.

    عنوان التعليمة التالية المراد جلبها.

    6. Multicore, Moore's Law & Intel x86

    متعدد الأنوية، قانون مور، وإنتل
    Low priorityAppeared in a sample paper: know the 4 consequences
    • Multicore: many processing units (cores) on one chip.
    • Moore's law (Gordon Moore, co-founder of Intel): number of transistors on a chip doubles about every year. Consequences: cost ↓, size ↓, performance ↑, power consumption ↓.
    • 8086: 16-bit, wider data path, instruction queue (prefetch).
    • Pentium: superscalar (several instructions in parallel).
    • Core: first Intel x86 dual core. Core 2: 64-bit; Quad = 4 cores. AVX = 256 then 512-bit vector instructions.
    • متعدد الأنوية (Multicore): عدة وحدات معالجة (أنوية) على شريحة واحدة.
    • قانون مور (جوردون مور، شريك مؤسس لإنتل): عدد الترانزستورات على الشريحة يتضاعف تقريبًا كل سنة. النتائج: التكلفة ↓، الحجم ↓، الأداء ↑، استهلاك الطاقة ↓.
    • 8086: ١٦ بت، مسار بيانات أعرض، طابور تعليمات (جلب مسبق).
    • Pentium: superscalar (عدة تعليمات بالتوازي).
    • Core: أول معالج x86 ثنائي النواة. Core 2: ٦٤ بت؛ Quad = ٤ أنوية. AVX = تعليمات متجهة ٢٥٦ ثم ٥١٢ بت.

    1. Computer Components & Software

    مكوّنات الحاسوب والبرمجيات
    3 von Neumann concepts again

    Same three von Neumann concepts as Chapter 1: stored data+instructions, addressable memory, sequential execution. Learn them once, use them in both chapters.

    Hardwired program: connecting components in a fixed configuration is a form of programming; the "program" is the hardware. Changing it means rewiring.

    Software: a sequence of codes or instructions. Part of the hardware reads each instruction and produces control signals. New program = new codes, no rewiring.

    نفس مفاهيم فون نيومان الثلاثة في الفصل الأول: بيانات وتعليمات مخزّنة، ذاكرة قابلة للعنونة، تنفيذ تسلسلي. احفظيها مرة وحدة وتنفعك في الفصلين.

    البرنامج المربوط بالعتاد (Hardwired program): توصيل المكوّنات بترتيب ثابت هو نوع من البرمجة، و"البرنامج" هو العتاد نفسه. تغييره يعني إعادة التوصيل.

    البرمجيات (Software): سلسلة رموز أو تعليمات. جزء من العتاد يقرأ كل تعليمة ويولّد إشارات تحكم (control signals). برنامج جديد = رموز جديدة بدون إعادة توصيل.

    • Memory (main memory): stores instructions and data.

    • I/O: وحدة إدخال (تستقبل البيانات والتعليمات وتحولها لإشارات داخلية) ووحدة إخراج (تعرض النتائج).

    2. Instruction Cycle (Fetch & Execute)

    دورة التعليمة
    LONG ANSWER · 4 MARKS"Very important"

    The basic job of a computer is executing programs. The processing needed for one instruction is called an instruction cycle, and it has two steps: Fetch then Execute. The processor repeats this loop for every instruction until the program ends.

    وظيفة الحاسوب الأساسية تنفيذ البرامج. المعالجة اللازمة لتعليمة واحدة تسمى دورة التعليمة (instruction cycle)، ولها خطوتان: جلب (Fetch) ثم تنفيذ (Execute). يكرر المعالج هذه الحلقة لكل تعليمة إلى أن ينتهي البرنامج.

    Try it yourself · جرّبيها بنفسك (press Next)
    FETCHEXECUTEINTERRUPT CHECK
    M[300] = 1940 (LOAD AC ← M[940])M[301] = 5941M[940] = 0003
    Exam answer · Instruction cycle (write this)

    Definition: the processing required for a single instruction. It has two steps.

    1. Fetch cycle

    • At the start of each cycle the processor fetches an instruction from memory.
    • The Program Counter (PC) holds the address of the next instruction.
    • After each fetch the processor increments the PC so the next fetch gets the next instruction in sequence.
    • The fetched instruction is loaded into the Instruction Register (IR).

    2. Execute cycle: the processor interprets the instruction in IR and performs the action. Four categories:

    • Processor–memory: transfer data CPU↔memory.
    • Processor–I/O: transfer data to/from a peripheral via an I/O module.
    • Data processing: an arithmetic or logic operation.
    • Control: change the sequence of execution (e.g. instruction at 149 says "next from 182", so PC is set to 182 and the next fetch comes from 182, not 150).

    التعريف: المعالجة اللازمة لتعليمة واحدة، وفيها خطوتان.

    ١. دورة الجلب (Fetch)

    • في بداية كل دورة يجلب المعالج تعليمة من الذاكرة.
    • عداد البرنامج (PC) يحمل عنوان التعليمة التالية.
    • بعد كل جلب يزيد المعالج قيمة PC ليجلب في المرة القادمة التعليمة التالية بالتسلسل.
    • التعليمة المجلوبة تُحمَّل في مسجّل التعليمات (IR).

    ٢. دورة التنفيذ (Execute): يفسّر المعالج التعليمة الموجودة في IR وينفّذ الإجراء. أربعة أنواع:

    • معالج–ذاكرة: نقل بيانات بين المعالج والذاكرة.
    • معالج–I/O: نقل بيانات من/إلى جهاز طرفي عبر وحدة I/O.
    • معالجة بيانات: عملية حسابية أو منطقية.
    • تحكم (Control): تغيير تسلسل التنفيذ (مثال: التعليمة في ١٤٩ تقول "التالية من ١٨٢"، فيصبح PC = ١٨٢ وتُجلب التعليمة التالية من ١٨٢ بدل ١٥٠).
    Memory trick for the loop: F-D-E = Fetch → Decode → Execute (the slides say Fetch / Execute; decoding happens when the processor "interprets" the instruction).

    3. Interrupts & the Interrupt Cycle

    المقاطعات
    Part of the instruction cycle slides

    Interrupt: a condition that makes the processor temporarily work on another task and then return to what it was doing.

    Interrupt cycle is added after execute. The processor checks for an interrupt signal:

    • None pending → go to fetch the next instruction of the current program.
    • Pending → (1) suspend the current program, (2) save its context (the PC value and other relevant data), (3) set PC to the start address of the interrupt handler routine.

    Multiple interrupts: if several occur, the system uses priorities: the highest priority is served first, then the rest in turn.

    المقاطعة (Interrupt): حالة تجعل المعالج يعمل مؤقتًا على مهمة أخرى ثم يعود لما كان يفعله.

    دورة المقاطعة (Interrupt cycle) تُضاف بعد التنفيذ. يفحص المعالج وجود إشارة مقاطعة:

    • لا توجد ← يذهب لجلب التعليمة التالية من البرنامج الحالي.
    • توجد ← (١) يوقف البرنامج الحالي، (٢) يحفظ سياقه (context) (قيمة PC وبيانات أخرى مهمة)، (٣) يضع في PC عنوان بداية روتين معالجة المقاطعة (interrupt handler).

    مقاطعات متعددة: إذا حدثت عدة مقاطعات يستخدم النظام الأولويات: الأعلى أولوية تُخدَّم أولًا ثم الباقي بالترتيب.

    4. Interconnection & the Bus

    الربط الداخلي والناقل
    "Focus on bus"Short / list

    Interconnection structure = the collection of paths connecting the modules (CPU, memory, I/O). A computer is basically a network of three module types.

    • Memory: N words, each with a unique address (0 … N−1); read or write controlled by control signals.
    • I/O module: like memory (read/write), but can control several devices via ports (each with an address) and can send interrupt signals.
    • CPU: reads instructions and data, writes data after processing, uses control signals, receives interrupts.

    هيكل الربط (Interconnection structure) = مجموعة المسارات التي توصل الوحدات (CPU، ذاكرة، I/O). الحاسوب في الأساس شبكة من ثلاثة أنواع وحدات.

    • الذاكرة: N كلمة، لكل واحدة عنوان فريد (٠ … N−١)؛ القراءة أو الكتابة تحددها إشارات التحكم.
    • وحدة I/O: تشبه الذاكرة (قراءة/كتابة) لكنها تتحكم بعدة أجهزة عبر منافذ (ports) (لكل منفذ عنوان) وترسل إشارات مقاطعة.
    • CPU: يقرأ التعليمات والبيانات، يكتب البيانات بعد المعالجة، يستخدم إشارات التحكم، ويستقبل المقاطعات.
    5 types of transfers · خمسة أنواع من النقل

    3. I/O → processor
    4. Processor → I/O
    5. I/O ↔ memory directly, without the processor = DMA (direct memory access)
    1. ذاكرة ← معالج (قراءة تعليمة/بيانات)
    2. معالج ← ذاكرة (كتابة بيانات)

    Exam answer · Bus & its three types

    A bus is a communication pathway connecting two or more devices. It is a shared transmission medium: a signal sent by one device can be received by all others. If two devices transmit at the same time, signals overlap and are garbled, so only one device can transmit at a time.

    • Data bus: carries data / instructions.
    • Address bus: identifies the source or destination of data.
    • Control bus: memory read/write signals, interrupt requests, clock signals.

    الناقل (Bus) هو مسار اتصال يربط جهازين أو أكثر. وهو وسط نقل مشترك: الإشارة التي يرسلها جهاز يستقبلها كل الأجهزة الأخرى. لو أرسل جهازان في نفس الوقت تتداخل الإشارات وتتشوّه، لذلك جهاز واحد فقط يرسل في الوقت الواحد.

    • ناقل البيانات (Data bus): يحمل البيانات / التعليمات.
    • ناقل العناوين (Address bus): يحدد مصدر أو وجهة البيانات.
    • ناقل التحكم (Control bus): إشارات قراءة/كتابة الذاكرة، طلبات المقاطعة، إشارات الساعة (clock).

    1. Key Characteristics & Access Methods

    الخصائص وطرق الوصول
    Sequential accessChoose / short

    Seven characteristics describe any memory system: Location, Capacity, Unit of transfer, Access method, Performance, Physical type, Physical characteristics & organization.

    • Location: internal (registers, main memory, cache) or external (disk, tape, flash drive).
    • Capacity: in bytes (1 byte = 8 bits) or words (8, 16, 32 bits).
    • Unit of transfer: number of bits read or written at once (a word or a block).

    سبع خصائص تصف أي نظام ذاكرة: الموقع، السعة، وحدة النقل، طريقة الوصول، الأداء، النوع الفيزيائي، الخصائص الفيزيائية والتنظيم.

    • الموقع (Location): داخلية (مسجّلات، ذاكرة رئيسية، كاش) أو خارجية (قرص، شريط، فلاش).
    • السعة (Capacity): بالبايت (١ بايت = ٨ بت) أو بالكلمات (٨ أو ١٦ أو ٣٢ بت).
    • وحدة النقل (Unit of transfer): عدد البتات المقروءة أو المكتوبة دفعة واحدة (كلمة أو كتلة).

    Performance · الأداء
    • Access time (latency): time to perform a read or write (address presented → data available). For non-random memory: time to position the read-write mechanism.
    • Memory cycle time = access time + extra time before the next access can start.
    • Transfer rate: rate data moves in or out. For random-access memory: Tr = 1 / cycle time.
    • زمن الوصول (Access time / latency): الزمن لتنفيذ قراءة أو كتابة (من تقديم العنوان إلى توفر البيانات). في الذاكرة غير العشوائية: زمن وضع آلية القراءة/الكتابة في الموقع.
    • زمن دورة الذاكرة (Cycle time) = زمن الوصول + زمن إضافي قبل بدء الوصول التالي.
    • معدل النقل (Transfer rate): سرعة دخول/خروج البيانات. للذاكرة العشوائية: Tr = 1 / cycle time.

    2. Memory Hierarchy

    هرم الذاكرة
    "If you go down, what happens?"Choose / direction

    Memory is organised in layers. Top (closest to the processor): registers → cache (L1, L2, L3) → main memory (DRAM) → hard disk → optical disk and tape. The first three are internal; the rest are external.

    الذاكرة مرتبة في طبقات. الأعلى (الأقرب للمعالج): المسجّلات (registers) ← الكاش (L1, L2, L3) ← الذاكرة الرئيسية (DRAM) ← القرص الصلب ← الأقراص الضوئية والشريط. أول ثلاثة داخلية والباقي خارجية.

    Exam answer · As you go DOWN the hierarchy
    • Cost per bit decreases (cheaper)
    • Capacity increases (bigger)
    • Access time increases (slower)
    • Frequency of access by the processor decreases

    The key to success is the last one: the CPU mostly finds what it needs in the fast upper levels.

    • التكلفة لكل بت تنقص (أرخص)
    • السعة تزيد (أكبر)
    • زمن الوصول يزيد (أبطأ)
    • تكرار وصول المعالج للذاكرة ينقص

    مفتاح النجاح هو الأخير: المعالج غالبًا يجد ما يحتاجه في الطبقات العليا السريعة.

    Quick rule: Faster = costs more · Bigger = costs less · Bigger = slower.

    3. Cache Memory & Its Principles

    الذاكرة المخبئية (الكاش) ومبادئها
    Slide 14 · "very important"

    Cache: a small amount of fast memory between the CPU and main memory. It may be on the CPU chip. It holds frequently used data so access speed approaches register speed, while the total memory stays large and cheap.

    الكاش (Cache): كمية صغيرة من الذاكرة السريعة بين المعالج والذاكرة الرئيسية. قد تكون على شريحة المعالج. تحتفظ بـالبيانات الأكثر استخدامًا فتقترب سرعة الوصول من سرعة المسجّلات، مع بقاء الذاكرة الكلية كبيرة ورخيصة.

    Exam answer · Cache principle (how a read works)
    1. The cache contains a copy of portions of main memory.
    2. When the processor reads a word, the system checks if it is in the cache.
    3. If yes (hit): the word is delivered to the processor.
    4. If no (miss): a block of main memory (a fixed number of words) is read into the cache, then the word is delivered to the processor.

    Multi-level: L1 (fastest, smallest), L2 (slower, larger), L3 (slower, larger still).

    1. الكاش يحتوي نسخة من أجزاء من الذاكرة الرئيسية.
    2. عندما يقرأ المعالج كلمة، يتحقق النظام هل هي موجودة في الكاش.
    3. إن وُجدت (hit): تُسلَّم الكلمة للمعالج.
    4. إن لم توجد (miss): تُقرأ كتلة (block) من الذاكرة الرئيسية (عدد ثابت من الكلمات) إلى الكاش، ثم تُسلَّم الكلمة للمعالج.

    متعدد المستويات: L1 (الأسرع والأصغر)، L2 (أبطأ وأكبر)، L3 (أبطأ وأكبر أيضًا).

    Think of: your desk (cache) vs the library (main memory). You keep the books you're using on the desk. If the book isn't there (miss), you bring the whole shelf section (block) from the library.
    تخيلي: مكتبك (الكاش) مقابل المكتبة (الذاكرة الرئيسية). تحتفظين على المكتب بالكتب التي تستخدمينها. إذا الكتاب مو موجود (miss)، تجيبين قسم الرف كامل (block) من المكتبة.
    Cache / main memory structure · البنية
    • Main memory has up to 2ⁿ words, each with a unique n-bit address.
    • It is viewed as blocks of K words: M = 2ⁿ / K blocks.
    • The cache has m lines (m is much smaller than M). Each line = K words + a tag + control bits (e.g. a bit showing whether the line was modified).
    • Because there are more blocks than lines, each line has a tag that says which block is currently stored there (the tag is part of the main memory address).
    • الذاكرة الرئيسية فيها حتى 2ⁿ كلمة، لكل واحدة عنوان من n بت.
    • تُعتبر كتلًا من K كلمة: M = 2ⁿ / K كتلة.
    • الكاش فيه m سطر (line) (m أصغر بكثير من M). كل سطر = K كلمة + وسم (tag) + بتات تحكم (مثلًا بت يبيّن هل عُدّل السطر).
    • لأن الكتل أكثر من الأسطر، كل سطر له tag يحدد أي كتلة مخزنة فيه حاليًا (والـ tag جزء من عنوان الذاكرة الرئيسية).

    5. Cache Mapping & Replacement

    تخطيط الكاش والاستبدال
    Doctor: "I don't think much will come, but know direct & associative"

    Mapping = linking main memory blocks to cache lines. Needed because there are fewer lines than blocks. Three techniques: direct, associative, set-associative.

    التخطيط (Mapping) = ربط كتل الذاكرة الرئيسية بأسطر الكاش. نحتاجه لأن الأسطر أقل من الكتل. ثلاث تقنيات: مباشر (direct)، ترابطي (associative)، ترابطي مجموعات (set-associative).

    Exam answer · Direct mapping
    Each main-memory block maps to only one possible cache line: i = j mod m where i = cache line number, j = main-memory block number, m = number of lines in the cache.
    Advantage: simple and inexpensive. Disadvantage: fixed cache location for each block. If a program keeps using two blocks that map to the same line, they keep swapping in and out (thrashing) and the hit ratio is low.
    كل كتلة من الذاكرة الرئيسية تُخطَّط إلى سطر واحد فقط محتمل في الكاش: i = j mod m حيث i = رقم سطر الكاش، j = رقم كتلة الذاكرة الرئيسية، m = عدد أسطر الكاش.
    الميزة: بسيط ورخيص. العيب: موقع ثابت لكل كتلة. إذا استمر البرنامج في استخدام كتلتين تُخطَّطان لنفس السطر، تتبادلان الطرد والإحضار باستمرار (thrashing) وتنخفض نسبة الـ hit.
    Exam answer · Associative mapping
    A main-memory block can be placed in any line of the cache (each block is associated with all cache lines). More flexible, but a replacement algorithm is needed.
    يمكن وضع كتلة الذاكرة الرئيسية في أي سطر من الكاش (كل كتلة مرتبطة بكل أسطر الكاش). أكثر مرونة لكنه يحتاج خوارزمية استبدال.
    Try it · جرّبي التخطيط المباشر
    Each block j goes to line i = j mod m. Try 0 4 0 4 with m = 4 (thrashing!) then 0 1 2 3 0 1 2 3.
    جرّبي 0 4 0 4 مع m = 4 (thrashing!) ثم 0 1 2 3 0 1 2 3.
    Exam answer · Replacement algorithms (when the cache is full)
    For direct mapping no choice exists (only one possible line), so no algorithm is needed. For associative techniques, four popular ones:
    • LRU (Least Recently Used): replace the block with no reference for the longest time.
    • FIFO (First In First Out): replace the block that has been in the cache longest.
    • LFU (Least Frequently Used): replace the block with the fewest hits.
    • Random: pick a line at random from the candidates.
    في التخطيط المباشر لا يوجد خيار (سطر واحد محتمل) فلا نحتاج خوارزمية. في الطرق الترابطية أربع خوارزميات شائعة:
    • LRU (الأقل استخدامًا مؤخرًا): استبدال الكتلة التي لم يُشر إليها منذ أطول وقت.
    • FIFO (الداخل أولًا يخرج أولًا): استبدال الكتلة الموجودة في الكاش منذ أطول مدة.
    • LFU (الأقل تكرارًا): استبدال الكتلة ذات أقل عدد hits.
    • Random: اختيار سطر عشوائي من المرشحين.

    Short answer
    2. Explain the major structural components of a CPU?
    • Control unit: controls the operation of the CPU and hence the computer.
    • ALU: performs the data processing (arithmetic and logic) functions.
    • Registers: storage internal to the CPU.
    • CPU interconnection: mechanism for communication among the control unit, ALU and registers.
    • وحدة التحكم: تتحكم بعمل المعالج وبالتالي الحاسوب.
    • ALU: تنفّذ معالجة البيانات (حساب ومنطق).
    • المسجّلات: تخزين داخل المعالج.
    • ربط المعالج: آلية اتصال بين وحدة التحكم وALU والمسجّلات.
    3. What is Core in multicore computer structure?
    When multiple processors reside on a single chip, it is a multicore computer. Each processing unit (control unit, ALU, registers, and perhaps cache) is called a core. A core is an individual processing unit on a processor chip, and may be equal in function to a CPU in a single-CPU system. Its parts: instruction logic (fetch and decode), ALU, load/store logic.
    عندما توجد عدة معالجات على شريحة واحدة يسمى الحاسوب متعدد الأنوية. كل وحدة معالجة (وحدة تحكم، ALU، مسجّلات، وربما كاش) تسمى نواة (core). النواة وحدة معالجة مستقلة على الشريحة وقد تعادل CPU في نظام بمعالج واحد. أجزاؤها: منطق التعليمات (جلب وفك)، ALU، منطق التحميل/التخزين.
    4. What is instruction cycle?
    The processing required for a single instruction is called an instruction cycle. It has two steps: Fetch (read the instruction from memory, address in the PC, then increment the PC, instruction goes to IR) and Execute (interpret the instruction in IR and perform the action). The processor repeats this for every instruction.
    المعالجة اللازمة لـتعليمة واحدة تسمى دورة التعليمة. لها خطوتان: الجلب (Fetch) (قراءة التعليمة من الذاكرة، العنوان في PC ثم يُزاد PC، وتذهب التعليمة إلى IR) والتنفيذ (Execute) (تفسير التعليمة في IR وتنفيذ الإجراء). يكرر المعالج ذلك لكل تعليمة.
    5. Define Bus Interconnection.
    A bus is a communication pathway connecting two or more devices. It is a shared transmission medium: a signal sent by one device is available to all others, so only one device can transmit at a time (otherwise signals overlap and are garbled). Three buses: data bus (data/instructions), address bus (source/destination of data), control bus (read/write, interrupt request, clock).
    الناقل (bus) مسار اتصال يربط جهازين أو أكثر. هو وسط نقل مشترك: الإشارة التي يرسلها جهاز تصل لكل الأجهزة، لذلك جهاز واحد فقط يرسل في الوقت الواحد (وإلا تتداخل الإشارات). ثلاثة نواقل: البيانات (بيانات/تعليمات)، العناوين (المصدر/الوجهة)، التحكم (قراءة/كتابة، طلب مقاطعة، ساعة).
    6. Explain Cache memory principles.
    • The cache stores copies of portions of main memory.
    • When the processor reads a word, a check is made to see if the word is in the cache.
    • If present, it is delivered to the processor (hit).
    • If not, a block of main memory (a fixed number of words) is read into the cache, and then the word is delivered to the processor (miss).
    • الكاش يخزن نسخًا من أجزاء الذاكرة الرئيسية.
    • عندما يقرأ المعالج كلمة، يتحقق النظام هل هي في الكاش.
    • إذا موجودة، تُسلَّم للمعالج (hit).
    • إذا لا، تُقرأ كتلة من الذاكرة الرئيسية (عدد ثابت من الكلمات) إلى الكاش ثم تُسلَّم الكلمة للمعالج (miss).

    B) Discuss different types of replacement algorithms.
    • LRU (Least Recently Used): replace the block that has been in the cache longest with no reference to it.
    • FIFO (First In First Out): replace the block that has been in the cache longest.
    • LFU (Least Frequently Used): replace the block with the fewest hits.
    • Random: pick a line at random among the candidates.
    • LRU: استبدال الكتلة التي لم يُشر إليها منذ أطول وقت.
    • FIFO: استبدال الكتلة الموجودة في الكاش منذ أطول وقت.
    • LFU: استبدال الكتلة ذات أقل عدد hits.
    • Random: اختيار سطر عشوائي من المرشحين.
    B) Define Hardwired Program.
    Hardwired program: connecting components in the desired configuration as a form of programming; the resulting "program" is in hardware form. To change it you must rewire. (Software replaced this: a sequence of codes, new program = new codes.)

    What is an interrupt? Draw and explain the instruction cycle with interrupts.
    Interrupt: a condition that causes the processor to temporarily work on another task and then return to the previous one.
    المقاطعة: حالة تجعل المعالج يعمل مؤقتًا على مهمة أخرى ثم يعود للمهمة السابقة.

    Explanation:

    1. Fetch cycle: read the instruction at the address in the PC, load it into IR, increment PC.
    2. Execute cycle: interpret the instruction and perform it (processor–memory, processor–I/O, data processing, or control).
    3. Interrupt cycle (added to the instruction cycle): the processor checks whether an interrupt signal is present.
      • No interrupt pending → go to fetch the next instruction of the current program.
      • Interrupt pending → (a) suspend the current program, (b) save its context (PC value and other relevant data), (c) set PC to the start address of the interrupt handler routine. After the handler finishes, the processor resumes the original program.

    Interrupt classes: Program, Timer, I/O, Hardware failure. With multiple interrupts, higher priority is served first.

    الشرح:

    1. دورة الجلب: قراءة التعليمة من العنوان الموجود في PC، تحميلها في IR، وزيادة PC.
    2. دورة التنفيذ: تفسير التعليمة وتنفيذها (معالج–ذاكرة، معالج–I/O، معالجة بيانات، أو تحكم).
    3. دورة المقاطعة (تُضاف لدورة التعليمة): يفحص المعالج هل توجد إشارة مقاطعة.
      • لا توجد ← يذهب لجلب التعليمة التالية من البرنامج الحالي.
      • توجد ← (أ) يوقف البرنامج الحالي، (ب) يحفظ سياقه (قيمة PC وبيانات أخرى)، (ج) يضع في PC عنوان بداية روتين معالجة المقاطعة. بعد انتهاء الروتين يكمل المعالج البرنامج الأصلي.

    أنواع المقاطعات: برنامج، مؤقت، I/O، فشل عتاد. عند تعدد المقاطعات تُخدَّم الأعلى أولوية أولًا.
